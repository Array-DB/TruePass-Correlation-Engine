# Correlation Engine

The temporal correlator evaluates bounded time proximity plus explicit shared context such as host, sensor, process identity, and cross-domain concurrence. Every contribution has a human-readable reason and weight.

Incident scoring combines correlation strength, anomaly novelty, and asset sensitivity into a bounded severity score. Candidate explanations and evidence IDs accompany the score.

The event graph represents events and entities and can rank candidate paths. Rankings are investigative hypotheses, not causal proof. Clock quality and timestamp uncertainty must be considered before interpreting tight temporal relationships.
