# TruePass v1.0.0

TruePass v1.0.0 completes Master Plan Phases 0–37: passive host/wireless telemetry, receive-only SDR/HackRF compatibility, DSP/RF anomaly analysis, cross-domain correlation, evidence integrity, optional timestamp anchoring, identity policy boundaries, API/dashboard/alerting, isolated voice/EEG research, hardening/privacy controls, automated testing, benchmarks, deployment configuration, documentation, CI/CD, and final integration.

## Known limitations

- Hardware HackRF capture requires operator hardware plus SoapySDR/SoapyHackRF and was not physically exercised in the build sandbox.
- PostgreSQL/pgvector external-service tests require a configured database; local SQLite is used for the automatic synthetic integration scenario.
- Correlation/anomaly scores are evidence aids, not proof of causation or compromise.
- Research voice/EEG outputs remain experimental and cannot independently authenticate or trigger response.
- Bitcoin anchoring requires an operator-supplied broadcaster and TruePass manages no wallet funds.
